# iOS App Assets

This directory should contain the following assets for the iOS app:

## Required Assets

1. **icon.png** (1024x1024)
   - Main app icon
   - Should be a square PNG without transparency

2. **splash.png** (2436x2436 or larger)
   - Splash screen image
   - Centered square design works best

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon foreground
   - Keep important elements in safe zone

4. **favicon.png** (48x48 or larger)
   - Web favicon
   - Small icon for web version

## Creating Assets

You can use design tools like:
- Figma (recommended)
- Adobe Illustrator
- Sketch
- Canva

Or generate them using:
- https://www.appicon.co/
- https://makeappicon.com/

## Asset Guidelines

- Use PNG format
- No transparency for main icon
- High resolution (will be scaled down)
- Simple, recognizable design
- Follows Apple Human Interface Guidelines
