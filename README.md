# Minecraft Multi-Bot Content Pipeline 🎮🤖

A comprehensive multi-bot Minecraft content pipeline with AI personalities, voice models, and 24/7 server management.

## 🚀 Quick Start

```bash
npm install
npm start
```

## ✨ Key Features

✅ **Bot Creation** - Working bot system with Mineflayer  
✅ **16 Voice Presets** - 8 male + 8 female voice models  
✅ **Streaming Schedule** - Bots hop on/off automatically  
✅ **24/7 AI Player** - Keeps Aternos server alive  
✅ **AI Memories** - Bots remember players & events  
✅ **iOS App** - .ipa file for Signulous deployment
