# Upload Your Mods Here

Place your Minecraft client mods in this directory and AvatarOS will automatically discover and learn how to use them.

## Supported Formats
- `.jar` files (Forge, Fabric, Quilt mods)
- `.js` files (Custom JavaScript mods)

## How It Works

1. **Upload**: Place your mod file in this directory
2. **Auto-Discovery**: AvatarOS scans for new mods on bot spawn
3. **AI Learning**: AI bots automatically analyze and learn capabilities
4. **Auto-Usage**: Bots figure out keybinds, commands, and features
5. **Memory Storage**: Learning is saved for future use

## Example Mods

Compatible with any standard Minecraft client mod:
- Simple Voice Chat
- JourneyMap
- Litematica
- Tweakeroo
- VoxelMap
- And more!

## Notes

- Mods are client-side and only affect individual AI bots
- AI bots will test discovered features in a safe manner
- Mod knowledge is stored in the AI memory system
- Each AI player learns independently but can share knowledge
- Some mods require specific Minecraft versions
