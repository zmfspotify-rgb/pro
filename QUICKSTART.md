# Quick Start Guide

## First Time Setup

### Option 1: Using the Windows Executable (Recommended for Windows users)

1. **Build the executable** (one-time setup):
   ```bash
   npm install
   npm run build
   ```

2. **Run the launcher**:
   - Navigate to the `dist` folder
   - Double-click `launcher.exe`

3. **Configure your settings**:
   - Use the arrow keys to navigate the menu
   - Select "⚙️ Configure Settings"
   - Edit the settings you need
   - Settings are automatically saved

### Option 2: Using Node.js Directly

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the application**:
   ```bash
   npm start
   ```

## What You Can Do

- **Configure Settings**: Edit all application settings through an interactive menu
- **Manage Bots**: Configure bot settings and behavior
- **View Status**: See current configuration and system status
- **Control Pipeline**: Start and stop the content pipeline

## Configuration File Location

All settings are saved to: `config/settings.json`

You can also edit this file manually if needed, but the application provides an easier interface.
