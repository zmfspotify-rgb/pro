# Upload Your Plugins Here

Place your Minecraft server plugins in this directory and AvatarOS will automatically discover and learn how to use them.

## Supported Formats
- `.jar` files (Bukkit, Spigot, Paper plugins)
- `.js` files (Custom JavaScript plugins)

## How It Works

1. **Upload**: Place your plugin file in this directory
2. **Auto-Discovery**: AvatarOS scans for new plugins on bot spawn
3. **AI Learning**: AI bots automatically analyze and learn capabilities
4. **Auto-Usage**: Bots figure out commands and features through experimentation
5. **Memory Storage**: Learning is saved for future use

## Example Plugins

Compatible with any standard Minecraft server plugin:
- Lifesteal SMP
- Factions
- WorldEdit
- EssentialsX
- LuckPerms
- And more!

## Notes

- Plugins are server-side and affect all players
- AI bots will test discovered commands in a safe manner
- Plugin knowledge is stored in the AI memory system
- Each AI player learns independently but can share knowledge
